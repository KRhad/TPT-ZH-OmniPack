# TPT-ZH-OmniPack / 万象沙盘整合版

> 本项目是以大量元素、化合物和材料为核心的自由沙盒整合版。项目不包含任务、成就、科技树或强制元素解锁，所有已启用内容均可直接使用。

这是一个非官方、以 The Powder Toy `100.0.399` 为基础、默认简体中文并保留完整英文界面的 GPL-3.0 大型内容整合客户端。项目目标不是任务游戏或生存游戏，而是让玩家打开普通沙盒后直接进行化学、冶金、核工业、生态、材料、电气、高温高压、爆炸和任意创造实验。

周期表统一提供元素单质、同位素和无机化合物；有机材料以及合金与工程材料使用各自的独立菜单分类。原版 TPT 元素仍保持原菜单位置，OmniPack 自造特殊内容也保留 rc8 原位置。

## 内容路线

正式路线以 [内容扩展路线图](docs/CONTENT_EXPANSION_ROADMAP.md) 为准：

- `0.1.x`：稳定中文、48 个扩展元素、四个现有模块、存档和发布基础；
- `0.2.0`：完整 118 元素周期表；
- `0.3.0`：常见无机化合物、酸、碱、盐和氧化物；
- `0.4.0`：合金、矿物、陶瓷、玻璃和工程材料；
- `0.5.0`：核素、衰变、核燃料和核工业；
- `0.6.0`：有机物、燃料、塑料、溶剂和工业化学；
- `0.7.0`：半导体、电池、超导、磁性和电子材料；
- `0.8.0`：生态、生物材料、污染、毒物和环境反应；
- `0.9.0`：菜单、周期表 UI、搜索、反应、性能和存档整理；
- `1.0.0`：内容冻结、全面测试和正式发布。

周期表 UI 只是选择入口，不是解锁系统。玩家既可以直接放置最终材料，也可以自行模拟矿石加工、化学合成、合金熔炼或核燃料循环。

## 来源与移植原则

外部模组只能作为只读来源。项目不会整库合并旧模组，不会覆盖官方元素 ID，也不会复制无源码、许可证不明或只有二进制的实现。与官方或现有 OmniPack 元素代表同一材料的候选不建立重复 ID；若兼容许可证下存在有价值的行为增量，则作为主元素行为优化重写合并，并回归保护主元素原行为。每个实际移植或增强项必须固定原仓库、commit、文件、许可证、移植类型、主 identifier、稳定 ID、主要改动和测试。

## 构建与测试

Windows x64 使用 MSYS2 UCRT64、Meson 和 Ninja。现有构建与测试工具必须保留，它们不是游戏内任务系统。常用命令：

```powershell
$env:PATH='C:\msys64\ucrt64\bin;C:\msys64\usr\bin;' + $env:PATH
meson compile -C build-ui-gas-electronics-final-clean
meson test -C build-ui-gas-electronics-final-clean --suite static --print-errorlogs
C:\msys64\ucrt64\bin\python3.exe -m unittest discover -s tools/tests -p 'test_*.py'
```

测试结果、未测试边界和正式门禁分别见 [TEST_MATRIX](docs/TEST_MATRIX.md)、[KNOWN_ISSUES](docs/KNOWN_ISSUES.md) 和 [VERSION_GATES](docs/VERSION_GATES.md)。自动测试通过不等于 GUI、视觉、长跑或公开发布通过。
