# TPT-ZH-OmniPack / 万象沙盘整合版

> 本项目是以大量元素、化合物和材料为核心的自由沙盒整合版。项目不包含任务、成就、科技树或强制元素解锁，所有已启用内容均可直接使用。

这是一个非官方、以 The Powder Toy `100.0.399` 为基础、默认简体中文并保留完整英文界面的 GPL-3.0 大型内容整合客户端。项目目标不是任务游戏或生存游戏，而是让玩家打开普通沙盒后直接进行化学、冶金、核工业、生态、材料、电气、高温高压、爆炸和任意创造实验。

## 当前真实状态

- 当前引擎登记了 419 个活动槽：官方 195 个，加上 OmniPack 224 个登记项；其中 `OMNI_PT_MSCR=278` 是隐藏兼容别名，不计入可玩内容，因此当前可直接选择材料为 418 个（官方 195、OmniPack 223）；`total_playable_materials>=300=true`。
- 当前扩展内容：工业冶金/工程材料 43 个可玩材料和 1 个兼容别名、局部生态 8、受控核工业与代表性核素 20、化学与无机物 60，以及周期新增元素 92；前四个可选模块默认启用，周期元素始终直接可用。
- 行为级去重已把旧金属碎料 `MSCR` 合并到官方 `BRMT`：官方金属粉保留原行为，只有携带专用可回收标记的 `BRMT` 才保存来源金属并按其熔点回炉。旧 ID 278 继续读取和迁移，但从菜单、搜索和 Lua 直接创建中移除，且永不复用。
- 当前稳定空间已安全扩展为 `PT_NUM=1024`、`PMAPBITS=10`；旧 `0..575` ID 全部不变。周期表严格复用 26 个现有纯元素实现，其余 92 个固定为 `370..461`；无机三批使用 `462..511`。工程材料区固定为 `512..575`，已实现 `SOLD..RFBK=512..532`，`533..575` 保留；代表性核素固定为 `H2IS..CF52=576..588`，`589..1023` 保留未来内容。OPS 第二类型字节、按来源位宽建立的 identifier palette、旧 8/9 位携带字段、Lua、菜单和两张 `1024²` 移动矩阵均已审计并自动验证；已知 identifier 即使来自更宽 OPS 的 1536 号槽，也会先映射到当前稳定 ID 再做范围检查。
- 已加入独立标准长式周期表面板，支持中文名、英文名、符号、原子序数和 identifier 搜索，支持常温状态、放射性、金属/非金属/类金属筛选、类别着色及镧锕系展开；面板只负责选择，不参与解锁。
- 所有已启用元素均可直接选择、放置，也可由普通 Lua 创建；没有发现进度、配方进度、存档进度或任务完成条件。
- 关闭任一内容模块会阻止对应元素的菜单/Lua 选择与新建；已有 OPS 粒子不删除，但对应冶金、生物、化学或核工业更新会在下一模拟刻暂停，重新启用后恢复。四模块禁用 OPS 运行回归覆盖 14 个粒子，其中包含高位 `NITI=520`、材料 `RFBK=532`、核素 `CF52=588`、邻近火焰但不得点燃的 `H2IS=576`、带来源类型的可回收 `BRMT`、第二批 `CARA=478` 和第三批 `AMCL=511`。
- 旧 OPS 中曾写入的 `omniAlchemy` 字段现在仅作为未知顶层字段被忽略，新存档不再写入它，旧粒子与间接元素字段保持不变。
- 图鉴在正文前明确显示“元素说明 / Element description”，模组元素说明同时以对应中英文名称开头。
- 当前仍是开发状态，`release_ready=false`；虽然可玩材料已达到 418、周期表为 118/118、三批 50 种精确无机材料、首批 9 种高位工程合金、12 种矿物/陶瓷/玻璃/建筑材料及 13 种代表性核素已完成，后续有机物、电子与生态污染材料族、正式 GUI 视觉矩阵、正式压力、长跑、公开源码远端、tag 和 Release 仍未完成。

## 内容路线

正式路线以 [内容扩展路线图](docs/CONTENT_EXPANSION_ROADMAP.md) 为准：

- `0.1.x`：稳定中文、48 个扩展元素、四个现有模块、存档和发布基础；
- `0.2.0`：完整 118 元素周期表；
- `0.3.0`：常见无机化合物、酸、碱、盐和氧化物；
- `0.4.0`：合金、矿物、陶瓷、玻璃和工程材料；
- `0.5.0`：核素、衰变、核燃料和核工业；
- `0.6.0`：有机物、燃料、塑料、溶剂和工业化学；
- `0.7.0`：半导体、电池、超导、磁性和电子材料；
- `0.8.0`：生态、生物材料、污染、毒物和环境反应；
- `0.9.0`：菜单、周期表 UI、搜索、反应、性能和存档整理；
- `1.0.0`：内容冻结、全面测试和正式发布。

周期表 UI 只是选择入口，不是解锁系统。玩家既可以直接放置最终材料，也可以自行模拟矿石加工、化学合成、合金熔炼或核燃料循环。

## 来源与移植原则

外部模组只能作为只读来源。项目不会整库合并旧模组，不会覆盖官方元素 ID，也不会复制无源码、许可证不明或只有二进制的实现。与官方或现有 OmniPack 元素代表同一材料的候选不建立重复 ID；若兼容许可证下存在有价值的行为增量，则作为主元素行为优化重写合并，并回归保护主元素原行为。每个实际移植或增强项必须固定原仓库、commit、文件、许可证、移植类型、主 identifier、稳定 ID、主要改动和测试。

来源记录见：

- `docs/MOD_SOURCE_CATALOG.csv`
- `docs/MOD_LICENSE_AUDIT.md`
- `docs/THIRD_PARTY_SOURCES.md`
- `docs/PORTING_LEDGER.md`

模组素材库已完成自动搜索、固定、提取和初步许可证分类；`license_audit_pass=false` 仍表示最终移植文件及资源的逐项人工复核尚未全部完成。

## 构建与测试

Windows x64 使用 MSYS2 UCRT64、Meson 和 Ninja。现有构建与测试工具必须保留，它们不是游戏内任务系统。常用命令：

```powershell
$env:PATH='C:\msys64\ucrt64\bin;C:\msys64\usr\bin;' + $env:PATH
meson compile -C build-isotope-batch1-final-clean
meson test -C build-isotope-batch1-final-clean --suite static --print-errorlogs
C:\msys64\ucrt64\bin\python3.exe -m unittest discover -s tools/tests -p 'test_*.py'
```

测试结果、未测试边界和正式门禁分别见 [TEST_MATRIX](docs/TEST_MATRIX.md)、[KNOWN_ISSUES](docs/KNOWN_ISSUES.md) 和 [VERSION_GATES](docs/VERSION_GATES.md)。自动测试通过不等于 GUI、视觉、长跑或公开发布通过。
