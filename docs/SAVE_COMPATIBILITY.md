# 存档兼容性

## 结论口径

- **完全兼容**：无需迁移，语义与粒子属性保持一致。
- **可迁移**：能可靠识别来源并无损映射到稳定标识符。
- **部分迁移**：部分元素或核心字段可映射，其余以占位和警告保留。
- **无法兼容**：来源无法辨认、实现缺失或核心模拟语义无法重现。

编译成功不能证明存档兼容；每项必须由固定样本的载入、重存、再载入和粒子统计支持。

## 安全要求

- 不依据单独数字 ID 猜测旧模组来源。
- 不把无法识别的粒子静默替换成当前同 ID 的官方元素。
- 缺失模块载入时列出内部标识符、中文名、来源和建议。
- 保存含 OmniPack 专属元素的沙盘时明确标记为模组存档，不能伪装成官方兼容存档上传。
- 发布包不得带个人存档、印章、账号资料或 `powder.pref`。
