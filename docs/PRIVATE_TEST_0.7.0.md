# TPT-ZH-OmniPack 0.7.0-dev 私有测试说明

这是纯沙盒内容扩展分支的 Windows x64 私有测试版，不是 1.0.0 正式版，也不是公开发布候选。它不包含玩家任务、成就、挑战、科技树、发现进度或强制解锁；所有已启用内容均可直接选择和放置。

## 本版范围

- 普通菜单可直接选择的材料共 `466` 种：官方 `174` 种、OmniPack `292` 种。引擎另有擦除工具和官方隐藏过渡/辅助类型；全部活动非别名类型合计 `487`，并有一个隐藏的旧存档兼容别名。
- 完整周期表为 `118/118`，全部可直接放置。
- OmniPack 当前登记 `293` 项，全部可见菜单代号均为唯一的四位大写字母。
- 当前最高稳定元素 ID 为 `DETG=685`；旧 ID 和 identifier 均未重新分配。
- 相比 `0.6.0-dev`，新增 20 种电子与特殊材料 `GAAS..DIEL=622..641`，以及 16 种生态与污染材料 `SOIL..DETG=670..685`。
- 周期表 `P` 按钮已移至独立区域；扩展气体改用与官方气体一致的柔和云团绘制方式。
- 图鉴正文以材料名称开头，并只描述玩家能够观察或利用的性质与反应。
- 本测试版仍为 `release_ready=false`。

## 建议启动方式

完全解压 ZIP 后再启动，不要直接在压缩包内运行。普通双击会使用 OmniPack 自己的应用数据目录；如果希望把本次测试数据完全隔离，可在解压目录打开 PowerShell 后运行：

```powershell
New-Item -ItemType Directory -Force .\test-data | Out-Null
.\tpt-zh-omnipack.exe ddir .\test-data
```

便携构建不应要求安装程序或注册文件关联。EXE 未签名，请先核对随包 `.sha256` 和 ZIP 内 `TEST-MANIFEST.txt`。

## 请优先检查

1. 简体中文默认显示是否清晰；切到英文再切回中文，菜单、搜索、周期表和图鉴是否正常。
2. 周期表 `P` 按钮是否始终可见、没有被右侧元素按钮或搜索按钮遮挡，并能正常打开周期表；请同时检查常用窗口大小和 Windows DPI 缩放。
3. 周期表能否按中文名、英文名、符号和原子序数搜索，并直接放置全部 118 种元素。
4. 放置官方气体及扩展气体（重点检查 `SMOG`），切换常用渲染模式，比较云团边缘、透明度和运动时的观感。
5. 搜索多组 OmniPack 材料，确认菜单代号始终是四位大写字母；查看图鉴，确认正文先写材料名称，并且没有“代理、事件预算、渲染实现、有限寿命”等开发说明。
6. 逐个搜索并放置生态与污染首批：`SOIL WWTR PEST HMET RCON MPLS OWST BLOM MOLD BLOD TOXN AMAT SLUD SMOG ARAN DETG`。
7. 检查土壤吸水与回收、污水净化、农药衰减、重金属与放射性污染、微塑料、有机废物、藻华、霉菌、血液、毒素、抗菌表面、污泥、烟霾、酸雨和洗涤剂清洗石油。
8. 保存包含 `DETG=685`、`DIEL=641`、`EACT=621`、核素和周期高位元素的场景，退出后重新加载，确认粒子没有丢失或变成其他元素。
9. 分别关闭冶金、生态、化学、核工业和电子材料模块，确认对应元素不能新建，存档中的已有粒子仍保留，但相关反应暂停。
