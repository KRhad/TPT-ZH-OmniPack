## 版本内容增长规则

| 版本 | 允许新增的内容 | 禁止合入的内容 |
|---|---|---|
| 0.1.0-test | 仅现有 48 元素的稳定性和发布修复 | 大型玩法或为数量新增元素 |
| 0.2.0 | 解决上述闭环缺口所需的最小反应、机器条件、示例与教程 | 无制造、无用途、无控制/回收的孤立元素 |
| 0.3.0 | 官方电子组合不足时，才增加审计通过的最小自动化能力 | 平行重造整套官方电路、全图扫描传感器 |
| 0.4.0 | 进度数据、解锁条件和独立模式 UI | 改变普通沙盒默认自由度 |
| 0.5.0 | 有预算、寿命、隔离和清理路径的危险系统 | 无限复制、全图传播、永久不可清理污染 |
| 0.6.0 | 内容索引、查询、关系和入口 | 裸内部枚举或内部 ID 充当玩家名称 |
| 0.7.0 | 版本化映射与合法迁移语料 | 静默错误替换或覆盖原存档 |
| 0.8.0 | 性能保护、模糊测试和恢复机制 | 用删除内容掩盖性能问题 |
| 0.9.0+ | 缺陷、兼容、平衡、性能、翻译、教程和 UI 修复 | 大型系统、大规模元素、无必要架构重写 |

## 0.2.0 用途审计入口

在 0.2.0 开发前，必须把每个正式元素的下列字段写入可机器审计的 registry，而不是只留在本汇总表：

```text
production
primary_use
secondary_use
consumption
side_products
hazards
controls
recycling
related_modules
tutorial_scene
stress_risk
```

当前优先审计项是基础金属来源、`SLAG`、`HUMS`、`NWST`、`STER`、`BIOF`、`CHLR`、`CATA`、`POLY`、`FERT` 与核结构材料。处理方式可以是补齐闭环、标记实验性并默认隐藏，或保留稳定 ID 并写迁移说明；不得删除后重排 ID。
