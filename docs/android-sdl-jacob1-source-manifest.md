# Android SDL Jacob1 Source Addendum

This directory preserves the Android SDL integration files from the local
`android-sdl-jacob1` workspace. Generated APKs, native libraries, object
files, and build output are intentionally excluded.

- Source workspace baseline: `cc6c7263502dfe0d22bcb9c639fbfae8f3ff9355`
- Local archive commit: `4c9891e56c2ffb960e0d0ff3c540b3b3a5a0f21`
- Preserved files: Android manifest/settings, Java settings, native build
  metadata, and the three SDL Android video/input sources.

The files are kept under `android-sdl-jacob1/` using their original relative
paths so they can be compared or applied without relying on the deleted local
workspace.
