# TPT-ZH OmniPack 1.1.0

This archive is a stable `1.1.0` artifact only when it is accompanied by the
same run's Validation Evidence bundle and that bundle reports every mandatory
gate as `PASS`. The release workflow first creates an immutable, uniquely named
staging candidate. The finalizer promotes those exact bytes only after importing
independent runtime-only Windows evidence and rejecting the negative attack suite.

Windows x64 releases use SDL 3. The optional SDL_GPU Vulkan thermal-diffusion
path validates against CPU and falls back to CPU on any failure. CUDA is not
implemented and is not required.

OmniAtmosphere saves use strict state version 3. Historical version 2 saves are
accepted only through deterministic migration and are rewritten as v3. Water and
solution mass/enthalpy coupling does not yet implement or claim full cross-phase
particle-to-gas momentum and kinetic-energy conservation.
