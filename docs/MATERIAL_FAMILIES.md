# 材料族与共享行为

本文件定义数据驱动行为的维护边界。共享逻辑只减少重复代码，不能把同族成员变成仅颜色不同的空壳。

| 材料族 | 共享行为 | 必须保留的成员差异 |
|---|---|---|
| 碱金属 | 水反应、氢气、热/火焰、盐生成 | 反应强度、熔点、密度、放射性 |
| 碱土金属 | 水/酸/氧反应、盐和氧化物 | 镁燃烧、铍毒性、焰色、镭衰变 |
| 卤素 | 氧化、腐蚀、毒性、卤化物和氢卤酸 | 常温状态、反应强度、放射性 |
| 稀有气体 | 惰性、扩散和通电发光 | 密度、导热、低温、氡/鿫衰变 |
| 过渡金属 | 导电、熔融、氧化、酸反应和合金参与 | 熔点、硬度、密度、磁性、催化、毒性 |
| 镧系 | 金属基础与有限氧化 | 磁性、荧光、激光、催化、玻璃、中子吸收 |
| 锕系 | 放射性、衰变热和屏蔽交互 | 裂变、中子行为、寿命和废料产物 |
| 超重元素 | 高能生成、有限寿命、受限衰变 | 衰变速度、粒子/热产额和短暂用途 |
| 酸/碱/盐 | 通用强度、中和、溶解和腐蚀 | 挥发性、氧化性、产物和温度范围 |
| 合金 | 熔融配比、冷却成型和氧化 | 强度、耐热、导电、耐腐蚀和实际用途 |
| 有机物/燃料 | 燃烧、热解、挥发和毒烟 | 闪点、相态、溶剂性、聚合路径 |
| 聚合物 | 软化/熔化、热解、燃烧和溶剂反应 | 耐热、阻燃、腐蚀性烟气和机械差异 |
| 核素 | 概率化衰变、热、粒子和屏蔽 | 半衰期缩放、衰变型、产物和中子响应 |
| 生态材料 | 营养、寿命、局部增殖和污染 | 生长介质、毒性、消毒和分解产物 |
| 爆炸物 | 受事件上限控制的点火、冲击、热和碎片 | 敏感度、爆速差异、烟气和用途 |
| 电子与特殊材料 | 光电、磁、电热、储能和状态切换 | 温度阈值、导电性、储能量、压力响应和光学状态 |

## 已落地：稀有气体首批

- `HE/NE/AR/KR/XE/RN/OG` 共用 `OmniPeriodic.cpp` 的固定 `3x3` 放电检查和每帧 `1024` 次事件预算；
- 密度、扩散、导热、热容量、放电概率、光子色带和局部加热均按成员区分；
- `HE` 在 20 K 以下每次只与一个局部邻居交换热量；`XE` 具有更强放电和更高局部热；
- `RN` 使用随机寿命并衰变为官方 `POLO`；`OG` 先变为 `RN`，每次衰变至多产生一个寿命有限的 `PHOT`；
- 温度和寿命经过沙盒尺度换算，不作为实验数据使用。

## 共享系统原则

- 同一材料已有官方或 OmniPack 主元素时，不新增近重复元素；经许可证复核的玩法增量重写进主元素，并以显式标记、模块门禁或窄条件保护原有行为；
- 反应表引用稳定 identifier，不把原子序数当内部 ID；
- 所有概率在 `[0,1]`，所有粒子生成反应有 `event_budget`；
- 状态转换、腐蚀、燃烧、衰变和生态更新使用局部邻域；
- 模块关闭后共享系统必须跳过对应登记项；
- 现实数据只作为设计依据，图鉴直接说明材料行为和适用范围。

## 已落地：工程合金与官方主元素增强

- `SOLD=512` 使用三份熔融锡与两份熔融铅的 `3x3` 配方，700 K 以上生成五份熔融锡铅合金；460 K 以下凝固；
- `CSTI..NITI=513..520` 共享同一 14 项合金表和 `2048/frame` 预算，但分别通过铸铁淬水脆裂、钛合金一次钝化、钨重合金中子吸收、锆合金热蒸汽产氢、康铜电阻升温和镍钛压力/热记忆状态形成玩法差异；
- 重叠配方按具体程度排序：镍铬钴先于镍铬，3:2 铜镍先于 3:1 铜镍，避免多余原料被较简单配方抢先消耗；
- 碳钢候选合并到既有 `STEL`，电阻加热候选合并到既有 `NCRM`；这两项是主元素行为优化，不新建重复 ID；
- `SOLD` 继承冶金模块的局部压力破坏和按来源回炉路径，反复火花每刻最多增加 45 K，可形成低熔点熔断连接；
- `MSCR=278` 的可回收来源金属语义已合并到官方 `BRMT=30`。普通官方 `BRMT` 不受影响，只有专用 `tmp4` 标记启用增强分支；
- 旧 278 仅为 OPS 兼容墓碑，不显示、不允许直接创建，也不计入材料数量。

## 已落地：矿物、陶瓷、玻璃与建筑材料首批

- 普通石英、玻璃、陶瓷、混凝土、石灰石/方解石和铁氧化物矿石继续复用 `QRTZ/GLAS/CRMC/CNCT/CACO/FEOX`；有价值行为合并到主元素或通用边界，不建立同概念副本；
- `GYPS..RFBK=521..532` 共用 `OmniMaterials.cpp` 的固定 `3x3` 邻域和 `1536/frame` 成功事件预算，模块关闭后更新入口立即停用；
- 五类矿石使用不同还原剂、温度和副产物；水泥固化复用官方 `CNCT`，长石制玻璃复用官方 `GLAS`，避免重复最终材料；
- `BSGL/QGLS` 具有不同熔点、导热和压力变化阈值，并接入官方折射、Cherenkov、破坏及氢氟酸反应边界；
- 石膏脱水/水合、氧化铝陶瓷烧结、石英熔体水淬和耐火砖烧制/极端水淬均由真实客户端断言，单帧材料事件峰值验证为 1536。

## 已落地：电子与特殊材料首批

- `GAAS..DIEL=622..641` 共 20 种材料，显示代号统一为四个大写字母，稳定 ID 与 identifier 不随菜单名称变化；
- 半导体覆盖砷化镓光电响应、氮化镓电脉冲发光及硼/磷掺杂硅；磁性材料覆盖铁氧体损耗、永磁吸引和软磁暂态；
- 压电、热电和超导材料分别响应压力、局部温差与 120 K 以下电流；石墨烯、碳纳米管、气凝胶和碳纤维复合材料具有不同导热、强度、氧化与压力破坏行为；
- 钴酸锂、石墨负极和固态电解质可传递电荷，过热正极会转化为钴并点燃邻近氧气；
- 相变存储、电致变色、正性光刻胶和介电陶瓷分别保存热状态、切换颜色、显影曝光区域和积累/释放电荷；
- 22 条催化合成路径同时识别固态和对应熔融态原料，既有化学配方优先，避免新配方抢占旧反应；
- 所有更新只检查 `3x3` 邻域并共享 `1024/frame` 成功事件上限；真实客户端验证 22 条合成、16 类行为和 1,024 次峰值。

## 已落地：生态、污染与环境材料首批

- `SOIL..DETG=670..685` 共 16 种新材料，与既有 `NUTR/ALGA/MYCL/SPOR/PATH/STER/HUMS/BIOF` 一起归入 Biology 模块；官方 `WATR/DSTW/SLTW/OIL/PLNT/WOOD` 保持主元素语义，不建立重复清水、盐水、石油、植物或木材；
- `SOIL` 储存至多八粒水并可受热释放；`WWTR` 经 `BIOF` 过滤或在藻类/营养盐旁形成藻华；`SLUD` 可由菌丝转为腐殖质或受热回收土壤和水蒸气；
- `PEST/HMET/RCON/MPLS/TOXN` 分别体现处理残毒、重金属水污染、有限放射性衰变、微塑料捕获/热解和生态毒害，均有明确的污水或污泥清理路径；
- `BLOM/MOLD/BLOD/AMAT` 分别以四次耗氧或寿命、有限有机原料与寿命、静止凝结和十二次处理量限制行为，不会无营养无限增殖；
- `SMOG` 使用官方式柔和气体云团，遇水蒸气形成 `ARAN`；酸雨可破坏土壤和常见金属，也可由 `CAOH` 转为蒸馏水和污泥；`DETG` 以三粒输入/三粒污水输出模拟石油清洗，不提供现实配方；
- 新旧生态逻辑共同调用 `OmniConsumeBiologyEvent`，全模块合计最多 `1024` 次成功事件/帧；真实客户端 1,100 组样本、模块禁用、独立 OPS 与 S14 smoke 均已覆盖，正式 S14 已完成 60 秒预热和 600 秒采样并通过独立门禁。
