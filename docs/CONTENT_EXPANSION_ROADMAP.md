# 纯沙盒内容扩展路线图

## 产品定义

TPT-ZH-OmniPack 是以数百种可操作元素、化合物、合金、核材料和特殊物质为核心的中文 The Powder Toy 大型自由沙盒整合版。所有已启用内容默认直接可用；收藏、最近使用、搜索和周期表只改善选择体验，不参与进度或解锁。

```text
task_driven_game=false
achievement_game=false
technology_tree=false
forced_unlocks=false
all_enabled_content_directly_available=true
target_playable_materials=300..450
```

## 当前基线

| 项目 | 当前值 |
|---|---:|
| 官方活动元素 | 195 |
| OmniPack 活动元素 | 48 |
| 总活动元素 | 243 |
| 已登记槽位 | 370 |
| 保留槽位 | 127 |
| 当前内容模块 | 4 |
| `PT_NUM` / `PMAPBITS` | 512 / 9 |
| 存档 | OPS1 / BZip2 / palette identifier |

现有稳定 ID 不重编号。ID 审计已确认：保留 `196..255` 供 Lua 动态元素优先分配；OPS 可保存第二个类型字节；92 个缺失周期元素固定使用 `370..461`；`462..511` 与既有模块空槽留给后续材料。512 槽理论容量足以达到约 450 个总材料，因此不扩大 `PMAPBITS`。

## Phase 1：方向清理

- 删除玩家炼金进度、选择锁、进度窗口、Lua 进度 API、OPS 写入和 0.4 打包配置；
- 删除任务、成就、挑战、科技树、发现和强制解锁的未来计划；
- 保留并重命名开发用反应样例、回归场景、构建脚本、压力测试和发布门禁；
- 旧 `omniAlchemy` OPS 字段忽略读取，新存档不再写入；
- 删除没有实际内容的玩家设置入口，保留稳定 ID 分区；
- 图鉴正文增加明确的“元素说明 / Element description”标签。

## Phase 2：周期表基础设施

1. 已审计官方、OmniPack 和合法模组候选对真实纯元素的代表性：复用 26 个，新增 92 个；
2. 已建立 `PERIODIC_ELEMENT_SOURCE_MAP.csv` 与原子序数到稳定 ID 的不可变映射；
3. 建立完整元数据、元素族共享逻辑和数据驱动反应层；
4. 建立标准长式周期表 UI、搜索、筛选、双语名称和类别着色；
5. 周期表 UI 不改变菜单可用性，也不读取进度。

## Phase 3：118 元素

按族分批实现并逐批登记、构建、测试和提交：

1. 氢与稀有气体；
2. 碱金属；
3. 碱土金属；
4. 硼族、碳族、氮族、氧族和卤素；
5. 第一、第二、第三过渡系；
6. 镧系；
7. 锕系；
8. 104–118 超重元素。

同族可共享底层逻辑，但必须有实际属性或用途差异。超重元素必须有有界寿命和事件预算，不能表现为永久稳定铁块。

## Phase 4–9：内容扩展

| Phase | 内容 | 目标范围 |
|---|---|---:|
| 4 | 酸、碱、盐、氧化物和工业无机物 | 50–100 |
| 5 | 合金、矿物、陶瓷、玻璃和建筑材料 | 45–90 |
| 6 | 代表性核素、核燃料、屏蔽与废料 | 15–30 |
| 7 | 有机物、燃料、溶剂、聚合物和高能材料 | 25–50 |
| 8 | 半导体、磁性、超导、复合与纳米材料 | 20–40 |
| 9 | 生态、生物材料、污染和毒物 | 20–40 |

最终材料可直接放置；生产链是可选沙盒玩法，不是获得材料的条件。

## Phase 10：内容整理

- 删除纯换色、行为等价和无用途候选；
- 完成中文名、英文名、符号、identifier、原子序数和分类搜索；
- 完成图鉴来源、属性、用途、危险和“游戏化而非科研级精确模拟”说明；
- 完成统一事件预算、模块关闭、OPS 往返、缺失元素和大型混合存档测试；
- 确认 300+ 材料仍在性能与 ID 容量内。

## Phase 11：1.0.0 发布

内容冻结后执行 clean Release build、全量自动测试、两小时长跑、GUI 双语/DPI/字体人工矩阵、包审计、PE 安全标志、许可证、对应公开源码、匿名克隆重建、`v1.0.0` tag 和正式 Release。

外部 PAT、正式远端授权和人工 GUI 是真实外部边界；边界存在时仍继续完成全部本地内容，但 `release_ready` 必须保持 `false`。
