# TPT-ZH-OmniPack 1.0.0

TPT-ZH-OmniPack is an unofficial GPL-3.0 physics-sandbox integration based on The Powder Toy 100.0.399. It provides Simplified Chinese and English interfaces and combines metallurgy, chemistry, nuclear technology, electronics, ecology, environmental materials, and a complete 118-element periodic-table picker.

The periodic table and material menus are selection indexes: choosing the same material through different routes always resolves to the same stable material identifier and save ID. Existing saves, module enable/disable behavior, Lua selection, and high-ID material mappings are retained.

## Run

Extract the ZIP to a new directory and run `tpt-zh-omnipack.exe`. This is a portable build and does not install file associations by default. Back up important saves before moving between game versions.

The Windows executable is currently unsigned. Windows may therefore display a publisher warning; verify the SHA-256 file supplied beside the ZIP before running it.

The startup screen shows `https://github.com/KRhad/TPT-ZH-OmniPack`. The game checks that public repository for updates and verifies exact size and SHA-256 before applying a download. Windows replaces the portable EXE; Android always delegates final confirmation to the system installer.
