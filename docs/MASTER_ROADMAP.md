# 万象沙盘总路线

本文件保留为历史链接的稳定入口。当前唯一有效的产品路线是 [CONTENT_EXPANSION_ROADMAP.md](CONTENT_EXPANSION_ROADMAP.md)。

项目是内容优先的自由沙盒，不包含玩家任务、成就、挑战、科技树、炼金进度、元素发现进度或强制解锁。开发任务、自动测试、测试矩阵、版本门禁和发布报告继续保留。

## 版本路线

| 版本 | 核心内容 | 完成定义 |
|---|---|---|
| `0.1.x` | 中文、英文、48 扩展元素、四模块、存档与发布基础 | 当前基线稳定，无玩家进度系统 |
| `0.2.0` | 118 元素周期表与选择 UI | 118 个可直接放置元素及族代表测试 |
| `0.3.0` | 无机化学 | 酸碱盐、氧化物与工业无机物 |
| `0.4.0` | 工程材料 | 合金、矿物、陶瓷、玻璃、建筑材料 |
| `0.5.0` | 核工业 | 代表性核素、衰变、燃料、屏蔽、废料 |
| `0.6.0` | 有机与工业化学 | 燃料、溶剂、有机物、聚合物、高能材料 |
| `0.7.0` | 电子与特殊材料 | 半导体、磁性、超导、复合与纳米材料 |
| `0.8.0` | 生态与污染 | 生态物质、生物材料、污染和毒物 |
| `0.9.0` | 内容整理 | 分类、搜索、图鉴、性能、反应和兼容性 |
| `1.0.0` | 正式发布 | 300+ 可玩材料和所有发布门禁通过 |

阶段、批次、数量口径和停止条件见主路线文件；本文件不再维护另一套相互冲突的版本计划。
