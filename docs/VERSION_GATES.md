# 版本硬门禁

## 通用规则

- 每个状态必须为 `true`、`false`、`not_tested` 或精确计数。
- 旧版本证据不能自动继承给新二进制；所有报告必须绑定 source commit 和 EXE/ZIP 哈希。
- 玩家任务、成就、科技树、炼金进度或强制解锁重新出现时，任何版本均不得发布。
