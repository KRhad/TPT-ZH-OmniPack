# TPT-ZH OmniPack 1.1.0

本压缩包只有在同时附带同一次运行的 Validation Evidence 包，且其中全部强制
门禁均为 `PASS` 时，才是稳定版 `1.1.0`。发布流程先生成唯一命名且不可变的
staging candidate；finalizer 导入独立 runtime-only Windows 证据并确认负向攻击
套件无法绕过后，才会原样提升同一份字节。

Windows x64 使用 SDL 3。可选 SDL_GPU Vulkan 温度扩散路径每次都与 CPU reference
比较，任何失败立即回退 CPU。CUDA 尚未实现，也不是运行依赖。

OmniAtmosphere 存档使用严格的状态版本 v3；历史 v2 仅通过确定性迁移读取，随后
只会写出为 v3。水与溶液的质量/焓耦合尚未实现或宣称完整的跨相粒子到气体动量、
动能守恒。
