## 启动

1. 将 `TPT-ZH-OmniPack-0.1.0-test-Windows-x64.zip` 解压到可写目录。
2. 用 `TPT-ZH-OmniPack-0.1.0-test-Windows-x64.zip.sha256` 校验 ZIP 哈希；ZIP 内的 `TEST-MANIFEST.txt` 校验每个文件。
3. 启动 `tpt-zh-omnipack.exe`。
4. 在“选项”的内容分区开关各模块，再从材料菜单或元素搜索中查找元素。

测试包刻意不包含偏好、图章、存档、脚本或账户数据；首次运行会自行创建独立于官方 TPT 的应用数据。便携测试包不会请求“安装”程序或注册 `.cps`、`.stm`、`ptsave://` 文件关联；若出现该提示，应视为构建配置回归并停止验收。当前 EXE 未签名，Windows SmartScreen 可能提示；不要绕过来源或哈希核验。

## 手动检查

1. 搜索 `ALUM`、`NUTR`、`NFUL` 和 `CHLR`，确认每项都有中英文图鉴内容。
2. 创建基础流程：熔融铜加锡形成青铜；营养盐、藻类、水和二氧化碳形成生态循环；
   对带燃料和慢化剂的中子发生器通电；以及催化剂辅助的燃料和化学路径。
3. 关闭一个已实现模块，确认该模块工具不可用。
4. 打开包含已关闭模块元素的存档，确认有正常加载、只读加载和取消三项选择；
   只读状态下本地保存及在线上传必须被阻止。
5. 在选项中切换简体中文和英文，确认菜单、内容标签与存档兼容提示均可读。
