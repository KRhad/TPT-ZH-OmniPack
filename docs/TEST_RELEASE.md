# Windows x64 测试版

## 测试范围

这是 TPT-ZH-OmniPack 的 Windows x64 内部测试版本。它包含官方 TPT 100.0
沙盘以及下列已实现模块：

- 工业冶金：ID `256..278`。
- 局部生态：ID `288..295`。
- 受控核工业：ID `328..334`。
- 高级化学：ID `360..369`。

其余预留 ID 区间不代表已完成玩法。自动化、灾害、炼金进度、兼容占位和来源模组
迁移均**不属于本测试版**。

## 启动

1. 将 `TPT-ZH-OmniPack-Test-Windows-x64.zip` 解压到可写目录。
2. 用 `TPT-ZH-OmniPack-Test-Windows-x64.zip.sha256` 校验 ZIP 哈希。
3. 启动 `tpt-zh-omnipack.exe`。
4. 在“选项”的内容分区开关各模块，再从材料菜单或元素搜索中查找元素。

测试包刻意不包含偏好、图章、存档、脚本或账户数据；首次运行会自行创建所需的应用数据。

## 手动检查

1. 搜索 `ALUM`、`NUTR`、`NFUL` 和 `CHLR`，确认每项都有中英文图鉴内容。
2. 创建基础流程：熔融铜加锡形成青铜；营养盐、藻类、水和二氧化碳形成生态循环；
   对带燃料和慢化剂的中子发生器通电；以及催化剂辅助的燃料和化学路径。
3. 关闭一个已实现模块，确认该模块工具不可用。
4. 打开包含已关闭模块元素的存档，确认有正常加载、只读加载和取消三项选择；
   只读状态下本地保存及在线上传必须被阻止。
5. 在选项中切换简体中文和英文，确认菜单、内容标签与存档兼容提示均可读。

## 已自动验证

- 使用 GCC 16.1.0 的 Windows x64 静态构建。
- Meson 静态测试集与 Python 工具测试集。
- 模块选择、冶金、化学、生物和受控核工业的 Lua 运行回归。
- 元素登记、双语本地化、图鉴内容与禁用模块存档门禁审计。

## 已知测试限制

- UI 视觉复核与语言切换交互仍需人工验证。
- OPS 往返、跨模组迁移、兼容占位与高粒子数性能样本尚未完成。
- 随包中文字体仍缺少可追溯名称、来源和许可证信息，这阻止正式公开发布。
