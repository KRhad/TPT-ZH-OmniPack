## 不可变规则

1. 官方 TPT 100.0 元素 ID `0..195` 原样保留，包含 ID `146` 的官方保留空位。
2. 内部标识符只使用 ASCII，存档、Lua、搜索和迁移以标识符为主要语义键。
3. 四字符显示代号保持英文、化学式或既有代号；中文正式名称属于本地化元数据。
4. 新元素必须显式声明固定 ID，不能依赖构造器列表顺序自动编号。
5. 删除候选元素不会回收 ID；废弃 ID 保留为 tombstone，避免后续元素整体移动。
6. 模块开关只改变可用性，不改变 ID，也不从载入的存档静默删除粒子。
7. 旧数字 ID 只有在来源版本已被可靠识别时才能迁移；否则显示缺失元素警告。

## 图鉴内容登记

`ELEMENT_REGISTRY.csv` 是稳定 ID、代号、双语名称、模块、来源、来源提交、许可证、生产、用途、危险、控制、清理、兼容状态和测试状态的权威登记。为兼容既有生成器，`code/zh_name/en_name/source/status/tests` 与原字段同时存在并由门禁强制逐字一致。`ELEMENT_CONTENT.csv` 保存图鉴需要的双语玩法长文本；每条内容记录都必须与登记中的规范 `OMNI_PT_*` identifier 一一对应，并同时提供以下英文和中文字段：

- 配方：已实现的局部输入和输出，或明确说明没有固定配方；
- 生产：玩家建立该路径的实际条件；
- 用途：在当前沙盘中可观察到的工程用途；
- 危险：当前规则导致的可玩风险，不能外推为现实安全结论。

`tools/element_registry_check.py` 拒绝别名漂移、模块区间错误、官方/保留槽伪造玩法声明，以及任何已实现 OmniPack 元素缺少具体生产、用途、危险、控制或清理信息。构建生成器和 `tools/element_content_audit.py` 继续拒绝缺少已实现元素、未知或大小写不一致 identifier、空字段、非法控制字符和不完整双语记录。图鉴只对内容非空的字段显示对应行，搜索同时索引这八个内容字段。官方元素继续显示其登记说明和热学属性，避免把本项目没有实现的生产路线写成事实。

## 已实现配方

所有配方温度均为开尔文。定比合金输入必须全部是熔融粒子，即 `type=LAVA` 且 `ctype` 为表中原料；一次匹配的全部原料必须同时位于触发粒子的 `3×3` 邻域内。

| 产物 | 实际输入比例 | 最低温度与相态 | 当前输出 |
|---|---|---|---|
| 钢 `STEL` | 4×铁 + 1×焦炭 + 1×助熔剂 | 4×`LAVA(IRON)` ≥ 1750 K；直接态 `COKE` ≥ 950 K；直接态或熔融态 `FLUX` ≥ 1050 K | 4×`LAVA(STEL)`；焦炭转为 `CO2`；助熔剂转为 `SLAG` 或 `LAVA(SLAG)` |
| 青铜 `BRNZ` | 3×铜 + 1×锡 | 全部熔融且 ≥ 1375 K | 4×`LAVA(BRNZ)` |
| 黄铜 `BRAS` | 3×铜 + 1×锌 | 全部熔融且 ≥ 1375 K | 4×`LAVA(BRAS)` |
| 镍铬合金 `NCRM` | 4×镍 + 1×铬 | 全部熔融且 ≥ 2200 K | 5×`LAVA(NCRM)` |
| 铝镁合金 `ALMG` | 4×铝 + 1×镁 | 全部熔融且 ≥ 950 K | 5×`LAVA(ALMG)` |
| 不锈钢 `SSIL` | 4×钢 + 1×铬 + 1×镍 | 全部熔融且 ≥ 2200 K | 6×`LAVA(SSIL)` |

定比合金会保留选中粒子总数，并把选中粒子的温度设为输入平均值。炼钢的四个钢粒子使用铁输入的平均温度，最低保持在 1800 K。多余原料不会被吞并；固定的局部遍历只选择满足表中数量的粒子。

## 生物性能边界与简化

- `OmniBiology.cpp` 不扫描 `NPART`、`parts.active` 或全图区域；每个成功事件均只读取固定 `3x3` 邻域。
- 所有成功事件共享每帧最多 1,024 次预算，`tmp3=currentTick+1` 防止同帧反复使用输入粒子。
- “简化生物模拟”是可用设置，不是仅有文本的占位：它不产生第二粒藻类或菌丝，而将相应营养/宿主转换为 `HUMS`，保留光合、分解、感染与处理的局部可见结果。
- 该模块不创建新粒子；完整模式中的局部扩增由将一粒已存在的 `NUTR` 转换为同类生物实现，粒子数不增加。

## 核工业性能边界

- `OmniNuclear.cpp` 的所有搜索固定在 `3x3`；不扫描 `NPART`、`parts.active` 或全图区域。
- 燃料转换、冷却和屏蔽共享每帧最多 512 次成功事件。中子发生器也使用相同预算，并且一粒火花最多触发一次生成。
- `tmp3=currentTick+1` 标记防止同一输入粒子在当前帧重复参与；按固定相邻遍历顺序选择目标，未使用反应随机数。
- 发生器先确认局部燃料及空槽，再创建官方中子；创建失败不会消耗其他粒子。冷却和屏蔽都只消费已找到的一粒相邻对象。
- 这是固定范围、固定产物的工程玩法近似；大型反应堆性能、存档往返、关闭模块后的兼容提示和辐射视觉仍属未覆盖范围。

## 高级化学反应表

所有条件仅检查触发粒子周围的 `3x3` 邻域；“催化剂旁”不代表完整反应器、真实管路、精确摩尔质量或工业安全规范。

| 路径 | 条件 | 输出 |
|---|---|---|
| 原油裂化 | `OIL` 邻近 `CATA`，催化剂 `temp >= 500 K` | `KERO` |
| 煤油裂化 | `KERO` 邻近 `CATA`，催化剂 `temp >= 650 K` | `GASO` |
| 高温裂化 | `KERO` 邻近 `CATA`，催化剂 `temp >= 1100 K` | `ACTY` |
| 乙炔聚合 | 2×`ACTY` 邻近 `CATA`，`450 K <= temp <= 800 K` | 2×`POLY` |
| 氯氢反应 | `CHLR + H2`，氯气 `temp >= 450 K` | 2×官方 `ACID` |
| 氨合成 | `LNTG + 3 H2` 邻近 `SPRK(CATA)`，`2 P` 以上、`500..1000 K` | 4×`AMON` |
| 氨中和 | `AMON + ACID` | 2×`FERT` |
| 肥料作用 | `FERT` 邻近 `PLNT + WATR` | `DUST`；将植物光合作用计数置为至少 2 |
| 发酵 | `YEST` 邻近 `PLNT + WATR`，`295..310 K` | `ETHL + CO2` |
| 过氧化氢制备 | 2×`WATR + O2` 邻近 `SPRK(CATA)`，`320..600 K` | 2×`PERO`，消耗氧气 |
| 过氧化氢分解 | 2×`PERO` 邻近 `CATA`，`temp >= 350 K` 且存在空位 | 2×`WATR + O2` |

燃料的燃烧继续使用官方 `FIRE` 对 `Flammable` 属性的接触点火机制；化学元素不通过高温自动转成 `FIRE` 绕过催化工艺。

## 化学性能边界与简化

- `OmniChemistry.cpp` 仅作固定 `3x3` 查找；不扫描 `NPART`、`parts.active` 或全图区域。
- 所有成功反应共享每帧最多 1,536 次预算，`tmp3=currentTick+1` 阻止输入粒子在同一帧被重复选取。
- 多输入氨合成明确排除已选择的三个氢粒子，不能用同一粒子重复满足计量条件。
- 过氧化氢分解会先创建氧气输出；创建失败时不消耗两个过氧化物输入。
- 这些规则是面向生产线玩法的整数粒子近似，不模拟产率、平衡常数、毒理、真实催化剂失活或连续反应器流量。

## 炭化规则

- 木材炭化：`WOOD` 必须处于 `650 K ≤ temp < 873 K`，`3×3` 邻域内有 `CRUC`，且没有 `O2` 或 `LO2`；条件连续保持 60 次更新后变成 `CHRC`。
- 煤炭炼焦：`COAL` 必须处于 `temp ≥ 950 K`，`3×3` 邻域内有 `CRUC`，且没有 `O2` 或 `LO2`；条件连续保持 90 次更新后变成 `COKE`。
- 任一条件中断都会把对应的连续计数清零。当前“缺氧坩埚”是局部邻接规则，不会验证宏观容器是否完全密封。

## 结构强度与 `Hardness`

本模块没有把 TPT 的 `Element::Hardness` 当作机械强度。现有 `ACID`、`CAUS` 和 `BASE` 反应会读取 `Hardness`，其数值是沿用引擎行为的化学交互系数，不能据此判断金属是否抗压。例如，铬的 `Hardness=1` 但压力破坏阈值为 105；镁的 `Hardness=40` 但压力破坏阈值只有 20。

机械差异由 `BreakPressureFor` 的独立阈值实现。单元格绝对压力达到阈值时，材料变为 `MSCR`，并在 `ctype` 中保留原材料 ID：

| 压力阈值 | 材料 |
|---:|---|
| 12 | `LEAD` |
| 18 | `TIN` |
| 20 | `MAGN`、`ZINC` |
| 25 | `ALUM` |
| 45 | `ALMG` |
| 48 | `COPR` |
| 60 | `BRAS` |
| 70 | `NCRM` |
| 75 | `BRNZ` |
| 82 | `NICL` |
| 90 | `COBT` |
| 105 | `CHRM`、`STEL` |
| 125 | `MOLY`、`SSIL` |
| 155 | `TSTL` |

这是一项可玩的压力破坏近似，不是应力张量、疲劳、晶粒或真实工程强度模拟。

## 性能边界与确定性

- 合金更新只处理白名单中的 `LAVA(ctype)`；每次收集当前粒子及八邻域，最多检查 9 个局部粒子，不扫描 `NPART` 或 `parts.active`。
- 铜腐蚀、镁燃烧、锌保护和炭化也只检查固定局部邻域。合金路径不递归创建粒子；镁燃烧最多以一个被消耗的氧粒子位置创建一个火焰粒子。
- 炼钢和定比合金共享每模拟帧 2048 次成功反应预算。该预算只限制合金/炼钢成功次数；其他局部行为依靠固定邻域和单次转换限制成本。
- 配方选择不调用随机数：当前粒子优先，其余位置按固定顺序遍历。`tmp3=currentTick+1` 标记阻止同一粒子在同一帧重复参加配方。
- 铜腐蚀和镁燃烧仍有明确概率，属于模拟随机行为；运行回归固定模拟 RNG 种子。不能把“合金匹配确定”扩大解释为整个冶金模块没有随机性。

## 简化假设

- 配方比例是整数粒子比例，不是质量分数、摩尔数或真实牌号标准。
- 温度门槛用于工程玩法，不模拟相图、共晶、溶解速率、保温曲线或压力对熔点的完整影响。
- 合金产物是单一元素，不记录晶粒、含碳量、热处理状态和微量杂质。
- 除炼钢明确产生 `CO2` 与 `SLAG` 外，其他合金反应不生成质量亏损或副产物。
- `CRUC` 邻接代表局部坩埚条件；当前没有验证完整炉体几何或气密性。
- 压力阈值读取单元格压力，不计算结构受力方向、厚度、屈服或疲劳。
- `MSCR.ctype` 只保留来源元素 ID，不保存破坏前的全部粒子参数或生产历史。
- 腐蚀、牺牲保护和镁燃烧是局部概率模型，不宣称科研级反应动力学。

## 正式收录门槛

每个默认启用且 `implementation_status=implemented` 的新增元素至少需要满足一项：

- 参与多步反应；
- 构成机器或生产线；
- 构成生命或能源系统；
- 产生可控制、可克制的新工程/灾害玩法；
- 与既有元素有明确联动；
- 具有可直接使用且区别明确的沙盒行为或材料用途。

只有颜色、密度或单一常数变化的近重复候选不得进入正式菜单。

## 存档迁移设计

- OSP/OPS 调色板中的 stable identifier 优先于旧数字 ID。
- 每个来源建立 `(source, source_save_version, old_id) -> stable_identifier` 映射。
- 同一旧 ID 对应多个来源时，必须先从模组专属 BSON 字段、版本、调色板或元素签名确认来源。
- 不能确认时创建兼容占位粒子，保留原标识、名称、来源和原始属性，并用中文警告列出处理方法。
- 关闭模块时提供继续加载、只读加载或取消三种明确选择。
