# 当前元素行为级去重审计

本审计只合并“代表同一材料或概念”的内容。名称相似不是合并依据；官方泛化材料与精确纯元素、同族但反应不同的材料继续并存。

重复候选采用“主元素增强”策略：有兼容许可证且存在真实玩法增量时，把增量重写进官方或当前 OmniPack 主元素，保留主元素的 ID、identifier、原有状态机和普通存档行为，不创建第二个菜单项。完全相同且没有增量的定义无需改代码。若被合并的 OmniPack 元素已有公开 ID，该 ID 仅作永久兼容墓碑。这是本整合包对官方元素实现的兼容增强，不表示上游 The Powder Toy 已接受该改动。

## 已合并

| 旧实现 | 官方主实现 | 裁决 | 兼容策略 |
|---|---|---|---|
| `OMNI_PT_MSCR=278` 金属碎料 | `DEFAULT_PT_BRMT=30` 金属粉 | 完全重复，合并 | 可回收来源金属逻辑迁入官方 `BRMT`；`MSCR` 从菜单和搜索隐藏并禁止直接创建；旧 OPS 粒子及载体仍识别 278，模块启用后的一个模拟刻迁移为带 `ctype` 和专用 `tmp4` 标记的 `BRMT`；278 永不复用 |

官方 `BRMT` 的原有普通金属粉和 `BRMT+BREC` 行为保留。只有带 `OmniRecoverableScrapMarker` 的粒子才按 `ctype` 所指来源金属的熔点回炉，避免增强逻辑改变普通官方存档。

## 审计后保留

| 候选组 | 不合并原因 |
|---|---|
| `FERT` / `NUTR` | 肥料是化学投料，营养盐是生态循环资源；二者存在 `HUMS+FERT+WATR -> NUTR` 的明确转换链 |
| `CHRC` / `BCOL` / `COAL` | 木炭、煤粉和煤具有不同来源、固体/粉末状态、焦炭生产及燃烧状态机 |
| `PATH` / 官方 `VIRS` | `PATH` 受营养、温度、消毒和生态预算约束；`VIRS` 使用官方跨元素感染/相变行为 |
| 精确酸、碱 / 官方 `ACID`、`BASE` | 精确材料生成不同盐和副产物；官方元素保留为泛化腐蚀材料 |
| 精确纯金属 / 官方 `METL`、`BMTL` | 官方材料是通用导体/可破坏金属，不代表具体化学元素 |
| `HE/NE/AR/KR/XE/RN/OG` / 官方 `NBLE` | 官方 `NBLE` 是泛化稀有气体；精确成员具有密度、放电、低温或放射性差异 |
| `KERO/GASO/ACTY` / 官方 `OIL/GAS/DESL` | 物态、裂化、燃烧、聚合和工业用途不同 |
| `CRUC` / 官方 `CRMC` | `CRUC` 是工艺容器条件，`CRMC` 是通用陶瓷材料 |
| `NCLT` / `WATR` | 核冷却剂具有受热、污染和反应堆专用状态；水仍是通用溶剂 |
| `RSHD` / `TTAN/LEAD` | `RSHD` 是可组装复合屏蔽材料，铅和钛仍保留各自元素行为 |
| `CATA` / `PTNM` | `CATA` 是通电配方工具，铂是可放置纯元素和局部催化材料 |

## 计数原则

- `PT_NUM=1024`，当前 `registered_slots=513`；公开稳定 ID 278 不能回收或分配给新材料。
- 引擎兼容别名仍注册以便旧粒子和间接类型安全迁移，但不计入“可直接选择材料”。
- 后续内容统计必须同时报告 `engine_active_elements`、`compatibility_aliases` 和 `playable_materials`，不得用别名凑 300 项门禁。
- 外部模组中的同概念行为增量进入 `B_rewrite_port`，目标是主元素而非新 ID；许可证不兼容或不明确时仍只能参考或拒绝。
